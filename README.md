# MetroList Android Music Player — Setup & Config Hub

Resources, equalizer profiles, and configuration guides for **MetroList**, the modern, open-source Android music player featuring Material You dynamic theming and background audio playback.

## Features & Included Tools
- `/configs/equalizer-presets.json`: Pre-tuned 10-band graphic equalizer curves (Acoustic, Vocal Clarity, and Bass Boost).
- `/configs/sample-lyrics.lrc`: Synchronized lyrics formatting template for local music libraries.
- Bit-perfect output and caching performance recommendations.

## Performance & Battery Optimization
- For continuous background playback on Android 12+, make sure to set app battery usage to **Unrestricted** in OS App Info.
- For high-bitrate FLAC files, enable 32-bit floating-point audio processing in developer playback settings.
